# SeeGram Personal

**SeeGram:** исходный клиент, стабильные релизы которого получает персональный форк.

**Персональный форк:** отдельное приложение пользователя со своими модулями, профилем и обновлениями.

**Модуль:** встроенная дополнительная возможность, которую пользователь включает отдельно.

**Запрошенное включение:** сохранённое желание пользователя пользоваться модулем. Оно сохраняется и при несовместимости.

**Работающий модуль:** модуль, который прошёл проверку для текущего приложения и продолжает отвечать.

**Самопроверка:** ограниченная проверка возможности запуска модуля без действий с перепиской.

**Диагностический отчёт:** локальный отчёт с версиями и причинами отказа, который пользователь может экспортировать для исправления.

**Кандидат обновления:** новая версия персонального форка, которую проверяют перед выпуском.

**Релиз персонального форка:** проверенная сборка, предназначенная для обновления отдельного приложения пользователя.
